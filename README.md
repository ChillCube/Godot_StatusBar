# Godot_StatusBar

An addon that can be used to display custom status bars, like healthbars, xp bars, etc in your godot game.

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/Godot_StatusBar.git
```

## Documentation
https://github.com/ChillCube/Godot_StatusBar/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon Godot_StatusBar
```
